# RONDO

## Visión

Rondo es una plataforma para organizar deporte amateur que conecta jugadores, clubes y reservas en una única experiencia. Permite crear partidos, completar equipos, reservar canchas, comunicarse mediante un chat asociado al encuentro y construir una reputación deportiva basada en la experiencia compartida.

Rondo busca convertirse en la plataforma de referencia para organizar deporte amateur.

Más que un sistema de reservas, Rondo conecta personas, organiza partidos, facilita la administración de clubes y mejora la experiencia completa antes, durante y después de cada encuentro deportivo.

El objetivo es que cualquier jugador pueda organizar un partido en pocos minutos, encontrar participantes compatibles, reservar una cancha cuando sea necesario y mantener toda la comunicación dentro de la plataforma.

---

# Problema

Actualmente organizar un partido implica utilizar múltiples aplicaciones y coordinar información de forma manual.

Un flujo habitual suele ser:

- Crear un grupo de WhatsApp.
- Buscar jugadores disponibles.
- Consultar quién puede asistir.
- Reservar una cancha en otra plataforma o por teléfono.
- Enviar ubicación.
- Coordinar pagos.
- Recordar horarios.
- Compartir resultados.

Toda esta información queda distribuida entre distintas herramientas, generando desorganización, pérdidas de tiempo y dificultades para repetir la experiencia.

Para los clubes, administrar reservas, promociones y la comunicación con sus socios también suele requerir múltiples sistemas o procesos manuales.

---

# Nuestra solución

Rondo centraliza toda la experiencia deportiva en una única plataforma.

Permite:

- Crear partidos.
- Invitar jugadores.
- Completar equipos automáticamente.
- Reservar canchas.
- Administrar clubes.
- Comunicarse mediante un chat asociado al partido.
- Valorar la experiencia entre jugadores.
- Descubrir nuevos compañeros de juego.
- Recibir notificaciones relevantes.
- Gestionar promociones de los clubes.

Cada partido se convierte en una entidad propia dentro de la plataforma, alrededor de la cual se organizan las reservas, los participantes, las conversaciones y la reputación de los jugadores.

# Público objetivo

## Jugadores

Personas que practican deportes amateur y organizan partidos con frecuencia.

Ejemplos:

- fútbol
- pádel
- tenis
- básquet
- vóley
- hockey
- cualquier deporte que requiera coordinación entre varias personas.

## Organizadores

Usuarios que habitualmente crean partidos, reservan canchas y gestionan participantes.

## Clubes deportivos

Instituciones que ofrecen infraestructura deportiva y necesitan administrar reservas, socios, promociones y comunicación con sus clientes.

# Objetivos del producto

## Para los jugadores

- Organizar partidos en pocos minutos.
- Encontrar jugadores compatibles.
- Reducir cancelaciones.
- Centralizar la comunicación.
- Construir una reputación deportiva.
- Descubrir nuevos compañeros.

## Para los clubes

- Simplificar la gestión de reservas.
- Incrementar la ocupación de las canchas.
- Fidelizar jugadores.
- Difundir promociones.
- Obtener métricas de uso.

---

# Propuesta de valor

Rondo no organiza únicamente reservas.

Organiza experiencias deportivas.

Cada partido tiene un ciclo de vida completo:

1. Creación.
2. Reclutamiento de jugadores.
3. Reserva de cancha (opcional).
4. Comunicación mediante chat.
5. Desarrollo del encuentro.
6. Valoraciones.
7. Resultados.
8. Cierre automático del evento.

---

# Principios del producto

Todas las decisiones del proyecto deberán respetar estos principios.

## Simplicidad

La experiencia debe ser sencilla incluso para usuarios con poca experiencia tecnológica.

## Mobile First

La mayor parte del uso ocurrirá desde dispositivos móviles.

## Comunidad

El valor principal de Rondo son las personas y las relaciones que genera.

## Flexibilidad

Los partidos pueden existir con o sin club y con o sin reserva.

## Escalabilidad

Toda decisión técnica deberá permitir incorporar nuevas funcionalidades sin romper las existentes.

---

# MVP

La primera versión deberá permitir:

- Registro e inicio de sesión.
- Gestión de perfil.
- Creación de partidos.
- Invitación de jugadores.
- Búsqueda de jugadores compatibles.
- Gestión de participantes.
- Reserva de canchas.
- Administración básica de clubes.
- Chat asociado al partido.
- Valoraciones entre jugadores.
- Notificaciones.
- PWA instalable.

---

# Qué NO es Rondo

Rondo no busca ser:

- una red social tradicional;
- una aplicación de mensajería general;
- un sistema exclusivo para un único club;
- un simple calendario de reservas.

La comunicación, las reservas y las valoraciones existen únicamente como herramientas para mejorar la experiencia deportiva.

---

# Futuro del producto

Una vez consolidado el MVP, Rondo podrá incorporar funcionalidades como:

- rankings deportivos;
- estadísticas personales;
- torneos;
- ligas;
- pagos integrados;
- suscripciones premium;
- inteligencia artificial para completar equipos;
- recomendaciones personalizadas;
- integración con calendarios;
- aplicación móvil mediante Capacitor;
- soporte para múltiples países e idiomas.

---

# Filosofía

Cada decisión de producto debe responder a una pregunta:

> ¿Esto hace que organizar y disfrutar un partido sea más fácil para jugadores y clubes?

Si la respuesta es sí, probablemente esté alineada con la visión de Rondo.

Si la respuesta es no, la funcionalidad deberá ser reconsiderada.
